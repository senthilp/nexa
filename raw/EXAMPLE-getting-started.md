# Example Source: Getting Started with Nexa

This is a sample source document to demonstrate the Nexa ingest workflow.

## What to do next

1. **Delete this file** if you don't need the example
2. **Add your own sources** to the `raw/` directory
3. **Tell Claude Code**: "Ingest raw/your-file.md"
4. **Watch the magic happen** as Claude:
   - Reads your source
   - Creates a summary page
   - Extracts entities and concepts
   - Updates the overview
   - Maintains cross-references

## Example ingest command

```
Ingest the article in raw/EXAMPLE-getting-started.md
```

Claude will walk you through the process.

## Tips for your first real source

- Web articles work great — use Obsidian Web Clipper to convert them to markdown
- PDFs can be read directly by Claude Code
- Images are supported — Claude can analyze them
- Start with one source to see how the workflow feels
- You can batch-ingest later once you're comfortable

## About this system

Nexa is designed to make personal knowledge bases actually maintainable. The LLM does the tedious work (cross-referencing, updating, consistency) while you focus on the interesting work (reading, thinking, asking questions).

The wiki grows with every source you add and every question you ask. Knowledge compounds instead of disappearing into chat history.

Happy knowledge building!
